# Tugas 04 React Dasar - Proyek Fullstack

## Deskripsi Proyek
Aplikasi ini merupakan kerangka tampilan (*frontend skeleton*) yang dibangun menggunakan **React (Vite)** dan **Tailwind CSS** sebagai bagian dari rangkaian pengembangan proyek aplikasi fullstack. 

## Fitur Kerangka Halaman:
1. **Navigasi Responsif**: Menu navigasi yang dapat beradaptasi pada tampilan mobile dan desktop.
2. **Dashboard**: Halaman utama dengan layout grid menampilkan ringkasan data statistik.
3. **Tabel Data**: Halaman untuk menampilkan daftar data dalam bentuk tabel terstruktur.
4. **Form Input**: Halaman formulir interaktif untuk menambah data baru.

## Alasan Pemilihan Tailwind CSS
Tailwind CSS dipilih karena menyediakan utilitas *grid* dan *flexbox* yang sangat responsif, memudahkan penyesuaian tata letak tampilan untuk ukuran layar mobile maupun desktop secara cepat dan efisien.
